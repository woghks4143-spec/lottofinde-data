개인정보처리방침

버전: v1.4 · 시행일: 2026-10-26
📢 변경 안내 (게시일 2026-10-19)
홈페이지에 내 번호 보관함, 앱 PRO 연결, 커뮤니티가 생기면서 각 기능을 쓸 때 저장하는 정보를 1·2·3·5·6·7·8항에 넣었어요. 앱만 쓰는 분께는 달라지는 내용이 없어요. 이전 버전(v1.3)

로또핀더(이하 "서비스")는 로또핀더 앱(이하 "앱")과 홈페이지 lottofinde.kr(이하 "홈페이지")를 운영하며, 이용자의 개인정보를 중요하게 생각하고 「개인정보 보호법」 및 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」을 준수하기 위해 노력합니다.

1. 처리하는 정보 항목 및 수집 방법

1-1. 앱

앱은 회원가입 없이 이용할 수 있으며, 이름·전화번호·이메일 등 이용자를 직접 식별하는 정보를 수집하지 않습니다. 다음 정보는 이용자의 기기 내부(AsyncStorage)에 저장됩니다:

  • 온보딩 답변(사용 빈도, 관심 기능)
  • 화면 설정(테마, 큰 글씨 여부)
  • 저장한 로또 번호(직접 입력 또는 QR 스캔)
  • 저장한 룰·필터·프리셋·번호 그룹·나만의 조합법
  • 귀찮이즘 받기 기록(PRO 사용자)
  • 주간 20조합 구매 기록(받은 조합, 결제 후 미지급 상태)
  • 알림 설정(켜기/끄기)
  • 기기 무작위 식별자(deviceSeed) — 앱이 처음 실행될 때 무작위로 만드는 값

기기 내부 정보는 아래 "외부로 전송되는 정보"를 제외하고는 운영자 또는 제3자에게 전송되지 않습니다.

외부로 전송되는 정보 (해당 기능을 사용할 때만):

  • 귀찮이즘 조합 받기·주간 20조합 발급 시: 기기 무작위 식별자(또는 그로부터 만든 값), 배정 순번, 배정 시각 → Google Firebase
  • PRO 멤버십·주간 20조합 결제 시: 앱 전용 익명 사용자 ID, 구매 기록(상품, 구매 일시, 구독 상태·만료일) → RevenueCat. 카드번호 등 결제수단 정보는 Google Play가 직접 처리하며 본 앱과 RevenueCat에 전달되지 않습니다.

선택적으로 사용하는 OS 권한:

  • 위치(선택): "가까운 판매점 찾기" 기능 사용 시에만 OS에 요청. 좌표는 기기 내에서 거리 계산에만 사용되며 서버로 전송되지 않습니다.
  • 카메라(선택): "QR 영수증 스캔" 기능 사용 시에만 OS에 요청. 이미지·QR 데이터는 기기 내에서만 처리되며 외부로 전송되지 않습니다.

1-2. 홈페이지 회원(선택)

홈페이지는 회원가입 없이도 볼 수 있으며, 회원 전용 기능을 쓰려는 분만 가입합니다. 가입할 때 다음 정보를 처리합니다:

  • 카카오 회원번호: 이용자가 카카오 로그인을 하면 카카오가 서비스에 알려 주는 숫자 식별값. 카카오 계정의 이름·이메일·전화번호·프로필 사진은 받지 않습니다.
  • 닉네임, 출생연도: 가입 화면에서 이용자가 직접 입력
  • 약관·개인정보 동의 버전과 일시, 가입 일시, 마지막 로그인 일시: 자동 기록

회원 기능을 쓸 때 저장하는 정보 (해당 기능을 쓸 때만):

  • 내 번호 보관함·조합 도구: 회원이 저장한 번호(회차, 번호, 만든 방법), 조합 필터링 룰, PRO 조합 도구의 프리셋·조합법·번호 그룹, 귀찮이즘 조합을 받은 개수
  • 앱 PRO 연결: 앱에서 받은 연결 코드로 연결하면 앱 전용 익명 사용자 ID(RevenueCat), 기기 무작위 식별자, 연결 일시, 구독 확인 결과(PRO 여부, 만료일)를 저장합니다. 구독 상태는 15분마다 RevenueCat에 다시 확인합니다. 연결 코드는 10분 동안만 쓸 수 있고, 만료된 코드는 주기적으로 삭제합니다.
  • 커뮤니티: 게시글, 댓글, 도전 번호, 당첨 게시판에 올린 사진(올릴 때 위치 정보 등 사진 속 정보를 지우고 다시 저장), 당첨 인증 글의 번호·회차·등수와 출처(보관함 저장 시각 포함), 추천·신고 기록, 커뮤니티 운영 정책 동의 일시. 닉네임과 게시물(도전 번호, 등록 시각, 채점 결과 포함)은 누구나 볼 수 있으며, 출생연도와 카카오 회원번호는 공개하지 않습니다.

쿠키: 홈페이지는 로그인을 유지하기 위해 다음 쿠키를 사용합니다. 광고·행태 추적용 쿠키는 사용하지 않습니다.

  • 로그인 유지 쿠키: 서버가 서명한 회원 식별값(30일, 브라우저 스크립트에서 읽을 수 없음)
  • 닉네임 표시 쿠키: 화면 위쪽에 닉네임을 보여 주는 용도(30일)
  • 로그인 보안용 임시 쿠키: 카카오 로그인 위조 방지와 가입 진행 확인(10~30분)

브라우저 설정에서 쿠키를 거부할 수 있지만, 그 경우 로그인을 할 수 없습니다.

PRO 조합 도구의 "나만의 조합법"을 만드는 중인 내용은 이용자의 브라우저에만 임시 저장되며 서버로 보내지 않습니다.

2. 정보의 이용 목적

  • 앱의 핵심 기능(로또 번호 통계 분석, 보관, 알림) 제공
  • 이용자의 편의 설정 보존(테마, 글씨 크기 등)
  • 유료 멤버십(PRO) 결제 상태 확인 및 기능 제공
  • 주간 20조합의 중복 없는 발급과 결제 후 미지급분 보존
  • 홈페이지 회원 식별과 로그인 유지, 회원 전용 기능(번호분석 전체 보기, 번호 저장과 자동 채점 등) 제공
  • 앱 PRO 구독 회원의 홈페이지 PRO 기능 제공(구독 상태 확인)
  • 커뮤니티 게시판 운영, 도전 번호 자동 채점과 랭킹, 신고 처리
  • 로또핀더 당첨 인증(보관함 저장 시각, 귀찮이즘 받은 기록, 앱 PRO를 연결한 회원은 연결한 기기의 주간 20조합·귀찮이즘 배정 기록 확인)
  • 만 19세 이상 여부 확인(출생연도)
  • 한 사람이 여러 계정을 만드는 등 부정 이용 방지

3. 보유 및 이용 기간

  • 기기 내부 저장 정보: 이용자가 앱을 삭제하거나 데이터를 초기화할 때까지
  • Google Firebase 배정 기록: 해당 회차 추첨일로부터 1년 이내에 삭제
  • 결제 관련 기록: 「전자상거래 등에서의 소비자보호에 관한 법률」에 따라 Google Play 및 RevenueCat이 정한 기간(대금 결제 기록 5년 등) 동안 보관될 수 있습니다.
  • 홈페이지 회원 정보(1-2항의 회원 기능 정보와 커뮤니티 게시물 포함): 회원 탈퇴 시 즉시 삭제합니다. 이용자가 카카오 계정 설정에서 로또핀더 연결을 끊은 경우에도 즉시 삭제합니다. 1년 동안 로그인하지 않은 계정은 홈페이지에 미리 알린 뒤 삭제할 수 있습니다.

4. 개인정보의 제3자 제공

서비스는 이용자의 정보를 제3자에게 제공하지 않습니다. 아래 5·6항의 처리 위탁은 서비스 제공을 위한 것입니다.

5. 처리 위탁

다음 서비스를 통해 일부 데이터를 처리합니다:

  • Google Play 결제 시스템 (Google LLC): 유료 결제 처리(결제수단 정보는 구글이 직접 처리하며, 본 앱은 결제 상태만 수신).
  • Google Firebase (Google LLC): 회차별 조합 배정 순번 운영(귀찮이즘·주간 20조합). 저장 항목은 기기 무작위 식별자(또는 그로부터 만든 값), 배정 순번, 시각이며 이것만으로는 개인을 식별할 수 없습니다.
  • RevenueCat (RevenueCat, Inc.): PRO 멤버십 구독 상태 검증 및 구매 기록 관리. 앱 전용 익명 사용자 ID와 구매 기록만 전달되며, 이름·연락처 등은 포함되지 않습니다. 홈페이지는 앱 PRO를 연결한 회원에 한해 이 ID로 구독 상태를 조회합니다.
  • GitHub (GitHub, Inc.): 회차별 당첨 데이터 다운로드. IP 주소 등 일반적 인터넷 접속 정보가 GitHub 서버 로그에 남을 수 있습니다.
  • Vercel (Vercel Inc.): 홈페이지 서버 운영과 커뮤니티 사진 저장(Vercel Blob). 홈페이지 접속 기록과 로그인 처리가 Vercel 서버에서 이뤄집니다.
  • Neon (Neon, Inc. · Databricks 계열): 홈페이지 회원 데이터베이스 운영. 1-2항의 회원 정보, 회원 기능 정보, 커뮤니티 게시물이 저장됩니다.

6. 개인정보의 국외 이전

위 서비스 이용에 따라 다음과 같이 정보가 국외로 이전될 수 있습니다:

  • Google LLC — 싱가포르(Firebase 서버)·미국 / 이전 항목: 기기 무작위 식별자에서 만든 값, 배정 순번·시각 / 목적: 조합 배정 / 보유: 3항과 같음
  • RevenueCat, Inc. — 미국 / 이전 항목: 앱 전용 익명 사용자 ID, 구매 기록 / 목적: 결제 검증, 홈페이지 PRO 연결 회원의 구독 확인 / 보유: 3항과 같음
  • GitHub, Inc. — 미국 / 이전 항목: 접속 정보(IP 등) / 목적: 데이터 다운로드
  • Vercel Inc. — 싱가포르(서버·사진 저장소)·미국 / 이전 항목: 홈페이지 접속 정보(IP, 브라우저 정보, 접속 시각), 로그인 쿠키 처리, 커뮤니티 사진 / 목적: 홈페이지 제공 / 보유: 접속 정보는 Vercel이 정한 짧은 로그 보관 기간, 사진은 글을 지우거나 탈퇴할 때까지
  • Neon, Inc. — 싱가포르(AWS 아시아 태평양 서버)·미국 / 이전 항목: 1-2항의 홈페이지 회원 정보, 회원 기능 정보, 커뮤니티 게시물 / 목적: 회원 관리와 회원 기능 제공 / 보유: 3항과 같음

이전 시기와 방법: 해당 기능을 사용할 때 네트워크(HTTPS·암호화 연결)로 전송됩니다. 귀찮이즘·주간 20조합·유료 결제 기능을 사용하지 않으면 Firebase·RevenueCat으로, 홈페이지에 가입하지 않으면 Neon으로 정보가 전송되지 않습니다.

7. 파기 절차 및 방법

  • 기기 내부 정보: 앱을 삭제하거나 [기능 → 데이터 백업 → 전체 초기화]를 실행하면 즉시 삭제됩니다.
  • Firebase 배정 기록: 보유 기간이 지나면 운영자가 복구할 수 없는 방법으로 삭제합니다.
  • 홈페이지 회원 정보(회원 기능 정보와 커뮤니티 게시물·사진 포함): 탈퇴하거나 카카오에서 연결을 끊으면 데이터베이스와 사진 저장소에서 즉시 삭제하며 복구할 수 없습니다. 탈퇴 시 카카오 연결도 함께 끊습니다.

8. 이용자의 권리와 행사 방법

이용자는 언제든지 다음의 권리를 행사할 수 있습니다:

  • 저장된 데이터 삭제: 앱 삭제 또는 [기능 → 데이터 백업 → 전체 초기화]
  • 알림 수신 거부: [기능 → 알림 설정] 또는 기기의 시스템 설정
  • 홈페이지 회원 정보 확인·탈퇴: 홈페이지 [내 정보]에서 확인하고 [회원 탈퇴]로 즉시 삭제. 카카오 계정 설정의 연결된 서비스에서 로또핀더를 끊어도 탈퇴로 처리됩니다.
  • 저장한 번호·룰 삭제: 홈페이지 [내 번호 보관함]에서 직접 삭제
  • 앱 PRO 연결 해제: 홈페이지 [내 정보 → 앱 PRO 연결]에서 끊기
  • 커뮤니티 글·댓글·사진 삭제: 글 화면에서 직접 삭제(고정수·제외수·예상수 도전은 마감 전까지, 사진은 글을 지우면 함께 삭제). 마감된 도전은 탈퇴하면 함께 삭제됩니다.
  • 그 밖의 열람·정정·삭제·처리정지 요청: 아래 보호책임자 이메일로 요청

9. 개인정보의 안전성 확보 조치

  • 수집하는 정보는 1항의 최소 항목으로 제한합니다. 홈페이지 회원가입에도 이메일·전화번호는 받지 않습니다.
  • 외부 통신은 HTTPS로 암호화하여 통신 구간을 보호합니다.
  • 로그인 유지 쿠키는 서버의 비밀키로 서명해 위조를 막고, 브라우저 스크립트가 읽을 수 없도록 설정합니다.
  • 회원 데이터베이스와 카카오 연동 키는 서버에만 보관하며, 접근 권한을 운영자로 제한합니다.
  • Firebase 데이터는 접근 규칙으로 삭제·변조를 제한합니다.
